# C01 師資管理 頁面設計

## 1. 頁面路由

- 路徑：`/professors`
- 元件：`ProfessorView.vue`
- 功能編號：`C01`

## 2. 版面結構

```
[C01 師資管理]
[新增師資 按鈕]（admin/ceo only）
─────────────────────────────────────
 ID | 姓名 | 電話 | 專長 | 狀態 | 操作
 1  | 王小明 | 09xx | 英語 | 啟用 | [編輯][刪除][上傳照片]
─────────────────────────────────────
```

## 3. 互動行為

- 點擊「新增師資」→ 彈出表單 Modal
- 點擊「編輯」→ Modal 帶入既有資料
- 點擊「上傳照片」→ 開啟檔案選擇器，選擇後立即上傳

## 4. 欄位說明

| 欄位 | 必填 | 驗證規則 |
|---|---|---|
| 姓名 | ✅ | 長度 ≤ 200 |
| 電話 | ✅ | 格式驗證 |
| 專長 | ❌ | 長度 ≤ 500 |
| 狀態 | ✅ | ACTIVE / INACTIVE |
