# A00 個人資料維護 頁面設計

## 1. 基本資料

- 頁面：`A00.jsp`
- 對應 BDD / SDD / TDD：`a00-personal-data`
- 使用者：員工本人、由 `F02` 帶入唯讀檢視的管理者

## 2. 頁面目的

- 提供員工維護個人基本資料、地址、語言能力、技能、證照、家庭狀況與工作經歷
- 提供個人照片上傳與 `閱讀員工守則` 入口
- 提供 F02 人員管理帶入的唯讀檢視，供管理者快速查看員工個資

## 3. 版面區塊

- 頁首與識別區：頁面標題、員工照片、員工基本識別資訊、`閱讀員工守則` 按鈕
- 基本資料表單區：姓名、電話、性別、血型、生日
- 基本資料唯讀區：員工編號、到職日期、所屬區域、部門、職稱、狀態
- 地址區：戶籍地址、通訊地址、`同上` 複製 / 同步設定
- 語言能力區：英語能力、日語能力、`Language Skills` 表格
- 技能區：一般軟體、程式語言、專業技能、自評能力
- 證照區：英文檢定、日文檢定、其他專業證照
- 家庭狀況區：家庭成員、關係、職業、聯絡方式、緊急聯絡人
- 工作經歷區：多段工作經歷表格
- 操作區：更換照片 / 上傳照片、儲存
- F02 唯讀檢視：頁首返回人員管理連結，不顯示系統側邊導覽

## 4. 欄位與顯示規則

- 生日與經歷 / 證照日期欄位使用 `date` 輸入元件
- 照片優先顯示尚未上傳的預覽，其次顯示目前照片，最後顯示預設頭像
- 到職日期須顯示後端回傳的 `join_date`
- 技能欄位以逗號分隔輸入多個值
- `同上` 啟用後，通訊地址同步戶籍地址內容
- 唯讀模式下保留資料顯示，輸入欄位唯讀、下拉選單停用，且隱藏照片、增刪列與儲存操作

## 5. 按鈕與動作

- `更換照片`：選取圖片檔案
- `上傳`：上傳新照片
- `儲存`：提交個人資料
- `同上`：將戶籍地址同步到通訊地址
- `閱讀員工守則`：開啟 `staff.pdf`
- `新增 / 移除`：維護語言、證照、家庭與工作經歷明細列

## 6. 互動規則

- 載入時顯示本人資料，若從 F02 帶入則改查指定員工資料
- 儲存成功後顯示成功訊息並保留最新回傳資料
- 照片上傳成功後立即更新頭像，失敗則顯示錯誤訊息
- `同上` 啟用後，戶籍地址變更時應同步更新通訊地址

## 7. 訊息設計

- 儲存成功：顯示 `儲存成功`
- 照片上傳成功：顯示 `照片上傳成功`
- 照片上傳失敗：顯示後端驗證錯誤或 `照片上傳失敗`
- 欄位驗證失敗：優先顯示後端第一個欄位錯誤訊息

## 8. 權限與狀態

- 一般員工僅維護自己的資料
- 從 `F02` 帶入時可進入唯讀檢視模式
- 唯讀模式不允許照片更新、資料儲存或明細列異動
