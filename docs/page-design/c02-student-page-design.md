# C02 學生管理 頁面設計（補充）

## 1. 頁面路由

- 列表路徑：`/students`
- 明細路徑：`/students/:id`（C046）
- 元件：`StudentView.vue`、`StudentDetailView.vue`

## 2. 版面結構（列表頁）

```
[C02 學生管理]              [新增學生] [匯出 Excel ▼]（management only）
篩選：[關鍵字搜尋][狀態▼][區域▼]
────────────────────────────────────────────────────────────────
 ID | 姓名   | 電話       | Email         | 區域  | 狀態 | 操作
  1 | 陳小美 | 09xx-xxxx | test@mail.com | 台北  | 啟用 | [明細][刪除]
────────────────────────────────────────────────────────────────
```

## 3. 匯出功能（C02-3）

- 按鈕：「匯出 Excel」（僅 management 角色可見）
- 下載格式：`.xlsx`
- 欄位：學號、姓名、電話、Email、區域、狀態、入學日期
