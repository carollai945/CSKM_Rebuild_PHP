# B02/D04 學員意見管理 頁面設計

## 1. 頁面路由

- 列表路徑：`/student-feedbacks`（功能編號 D04）
- 明細路徑：`/student-feedbacks/:id`（功能編號 D040）
- 元件：`StudentFeedbackView.vue`、`StudentFeedbackDetailView.vue`

## 2. 版面結構（列表頁）

```
[D04 學員意見管理]                          [新增意見]
篩選：[學員姓名搜尋][狀態▼][開始日期][結束日期][重置]
────────────────────────────────────────────────────
 ID | 學員 | 意見摘要 | 狀態     | 日期       | 操作
  1 | 陳小美 | 課程進度太快... | 🟡待處理 | 2026-07-01 | [明細][刪除]
────────────────────────────────────────────────────
```

## 3. 版面結構（明細頁）

```
[D040 學員意見明細]                          [← 返回]
─── 基本資訊 ───
意見編號：1   學員：陳小美   狀態：🟡待處理   建立日期：2026-07-01
─── 意見內容 ───
「課程進度太快，希望可以調整。」
─── 更新狀態 ───
狀態：[已結案▼]   回覆：[_______________]   [儲存]
```

## 4. 狀態對照

| 狀態碼 | 顯示文字 | 顏色 |
|---|---|---|
| OPEN | 待處理 | 橘色 |
| IN_PROGRESS | 處理中 | 藍色 |
| RESOLVED | 已結案 | 綠色 |
